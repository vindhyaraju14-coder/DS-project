# Data Science Digital Library

An interactive data science learning site with module guides, experiments, tools, and a browser-based Python editor.

## Deploy on Netlify

[Deploy this repository to Netlify](https://app.netlify.com/start/deploy?repository=https://github.com/vindhyaraju14-coder/DS-project), then authorize Netlify and select **Deploy**. Netlify builds the site from `main` and provides a public `*.netlify.app` URL when deployment completes.

## Run locally

```bash
npm install
npm run dev
```
